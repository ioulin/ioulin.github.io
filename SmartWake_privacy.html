개인정보처리방침

SmartWake - 스마트폰 액정 보호 · 시행일자: 2026년 7월 25일

SmartWake(이하 "본 앱")를 개발한 개발자(이하 "개발자")는 이용자의 개인정보를 소중히 여기며 본 방침을 통해 본 앱이 어떤 정보를 다루는지 안내합니다.

1. 수집하는 개인정보

본 앱은 어떠한 개인정보도 수집하지 않습니다. 인터넷 권한을 요청하지 않으며 회원가입, 로그인, 광고 SDK, 분석도구를 사용하지 않습니다.

2. 기기 안에만 저장되는 정보

저장 정보목적보관 위치보관 기간
액정 보호 설정이전 설정 유지Room삭제 또는 초기화 시
예외 앱 목록예외 앱 기능Room삭제 시
일별 사용 통계사용 기록 표시Room90일 후 자동 삭제
세션 복구 정보재부팅 후 복구DataStore세션 종료 시 삭제
모든 정보는 이용자 기기에만 저장되며 외부 서버로 전송되지 않습니다.

3. 접근 권한

권한사용 목적
SYSTEM_ALERT_WINDOW반투명 오버레이 표시
PACKAGE_USAGE_STATS예외 앱의 패키지명 확인
POST_NOTIFICATIONS상태 알림 표시
RECEIVE_BOOT_COMPLETED세션 자동 복구
FOREGROUND_SERVICE백그라운드 동작
WAKE_LOCK화면 켜짐 유지

접근성 서비스, QUERY_ALL_PACKAGES, 위치, 연락처, 카메라, 마이크 권한은 요청하지 않습니다.

4. 제3자 제공 및 광고

광고 SDK, 분석 도구, 결제 모듈을 포함하지 않으며 어떠한 정보도 제3자에게 제공하지 않습니다.

5. 아동의 개인정보

개인정보를 수집하지 않습니다.

6. 정보의 삭제

앱 삭제 시 저장된 데이터는 삭제되며 일별 사용 통계는 90일 후 자동 삭제됩니다.

7. 개인정보 처리방침 변경

법령·정책 또는 기능 변경 시 본 문서를 통해 고지합니다.
